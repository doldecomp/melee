Method. Comments and string literals are blanked, then each site is classified once by its outermost form: *(f32*)((u8*)p + 0xE0) is one cast+offset, not three casts. M2C_FIELD(p, T*, off) is the same shape behind a macro.

Match hacks. Every #pragma other than push/pop plumbing is one site, guarded by MUST_MATCH or not. Each #ifdef MUST_MATCH region holding real code is one site, labelled by what it contains; a region holding only pragmas is counted under those pragmas.

Precision. ptr-to-int and raw-offset are heuristic: an identifier counts as a pointer when it is declared with a * in the same function or at file scope, and narrow casts (u8, s16) are excluded. Every other category is syntactic.

Freshness. Regenerated by tools/cleanup_index.py on every push. Line links point at the revision that built this page. Filters live in the URL, so a filtered view is a shareable link.
